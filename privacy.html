Privacy policy

Last updated: 23 October 2026

YouTube scraper is a private, internal automation tool. It is used only by its owner and is not offered to anyone else.

What data the tool accesses

  • Google Drive: the tool creates folders and Markdown files in the owner's own Google Drive and checks which videos were already saved. It does not read, share or delete any other files.
  • YouTube: the tool reads public video information (titles, view counts, publish dates) through the YouTube Data API.

How data is used and stored

Data is used only to save video transcripts to the owner's Google Drive. Access credentials are stored as encrypted secrets of a private GitHub repository. No data is sold, shared with third parties or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
